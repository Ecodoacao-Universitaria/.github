# Eco Doação

Organização criada para administrar os projetos da disciplina de Engenharia de Software da Universidade Federal Rural de Pernambuco.

## Projeto

O projeto consiste em um sistema web que tem como objetivo incentivar e facilitar o processo de doações, oferecendo insígnias, pontos e rankings como incentivo ao usuário. Além disso, gera certificados que podem ser adicionados ao currículo.
